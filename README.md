# Health-Monitoring
Developed an ESP32-based IoT healthcare prototype designed to assist paralysis patients with health monitoring and basic communication. The system integrates flex sensors, thermistor, DHT temperature/humidity sensor, OLED display, LEDs, and buzzer to collect and display sensor data. Implemented a Wi-Fi-enabled web interface that allows a patient to communicate specific demands, such as requesting medicine, to a caregiver. The ESP32 processes sensor inputs, provides local visual/audible alerts, and hosts the web-based patient-demand interface. This project demonstrates practical applications of embedded systems, IoT, sensor interfacing, wireless communication, and assistive technology.

SmartAssist – IoT-Based Patient Health Monitoring System
Developed an ESP32-based assistive healthcare prototype using flex sensors, thermistor, DHT sensor and OLED display for monitoring and patient interaction. Implemented a Wi-Fi web interface for patient demands such as medicine requests, along with LED/buzzer alerts for caregiver assistance.
